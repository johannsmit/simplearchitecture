# SimpleArchitecture 0.74.6

A faster start: the app downloads much less before first use.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Less to download at the start**: the Admin pages (except Models) and the Help pages now load when they are first opened, and the diagram canvas loads when a model first opens. The script needed for the first page drops from about 500 kB to about 405 kB, and the main file from 500 kB to 85 kB.
- **A smaller installed app**: the offline copy that the installed app keeps drops from about 2.7 MB to about 1.2 MB. The diagram layout engine is no longer part of it; it is downloaded and kept the first time a diagram opens, so diagrams work offline after that. See the [Security overview](https://github.com/johannsmit/simplearchitecture/blob/v0.74.6/guide/security-overview.md).
- **Try again after a page fails to load**: if a page can't be downloaded, for example because a new version was installed while the app was open, Try again now reloads the app instead of showing the same message again.

## Upgrade

There are no database changes: start 0.74.6 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.6/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
