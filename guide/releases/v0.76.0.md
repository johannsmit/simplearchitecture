# SimpleArchitecture 0.76.0

One layout for the details panel on the right, for elements and relationships alike.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Round buttons at the top right**: an element's **Copy link** and, in Modelling, **Delete** are round icon buttons at the top right of the panel, with Copy link to the left of Delete. A relationship's **Delete** is a round button in the same place. See [Using the app](https://github.com/johannsmit/simplearchitecture/blob/v0.76.0/guide/using-the-app.md#the-details-panel).
- **One Properties section, one order**: every property sits in a **Properties** section that can be collapsed. Elements and relationships share the order: Name (or Label), Description, Architecture state, Type, then the rest in alphabetical order, Admin-defined properties and Functions included. See [Modelling](https://github.com/johannsmit/simplearchitecture/blob/v0.76.0/guide/modelling.md).
- **Relationships collapsed**: an element's **Relationships** section starts collapsed and shows its count. **Add relationship** (or `R`) opens it.
- **Architecture state as three choices**: an element's Architecture state is now picked from Deprecate, Current and Target, like a relationship's, and saves at once. A stored value that isn't one of the three shows a hint until one is picked.
- **Less clutter**: the ID at the bottom of the panel, a relationship's "Back to …" link and the element panel's **Show on canvas** button are gone. To go back from a relationship, pick the element (or press `Esc` in Viewing). In the catalog in Viewing, double-click a row or press `Enter` to focus its element on the canvas.

## Upgrade

There are no database changes: start 0.76.0 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.76.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- An element's Architecture state can't be cleared back to "not set" in the panel once picked.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
