# SimpleArchitecture 0.74.0

Admins can now read the application logs, in the app and through the MCP endpoint.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **A Logs page in the Admin space** ([#84](https://github.com/johannsmit/simplearchitecture/issues/84)): choose a date range (today by default, at most 31 days) and, if you like, a level, and see what the server recorded, newest first. Open **Details** on an entry to see its extra fields. At most 1,000 entries are shown at a time; narrow the dates or the level to see the rest.
- **A `get_logs` tool on the MCP endpoint**, with the same date range, level and limit. It is there only for people with the Admin role.
- **Logs are kept in the database for 30 days.** Credentials are never stored: the same redaction as the server's own log output applies.

See [Admin](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/admin.md) and [Connect an AI agent](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/connect-an-ai-agent.md).

## Upgrade

There is one new database migration, which runs when 0.74.0 starts. Only entries logged after the upgrade are shown. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
