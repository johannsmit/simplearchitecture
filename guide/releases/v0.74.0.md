# SimpleArchitecture 0.74.0

Admins can now read the application logs in the app, and their AI agents can fetch them through the MCP endpoint.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Admin → Logs** ([#84](https://github.com/johannsmit/simplearchitecture/issues/84)): a simple log viewer for the Admin role. Choose a date range (whole UTC days, today by default, at most 31 days) and a minimum level. Lines show newest first, with the time in UTC, the level and the message; open a line to see all its fields.
- **At most 1,000 lines per read.** When more lines match, the newest 1,000 are shown with a notice to shorten the range or raise the level.
- **`get_logs` on the MCP endpoint**, for people with the Admin role only. It takes the same date range (today by default) and minimum level. Other roles don't see the tool.
- **Kept for 30 days.** The app keeps a copy of each log line in the database, already redacted as on standard output, and removes lines older than 30 days. Standard output logging doesn't change.
- **Audited and limited.** Each read is logged with who read which range, never the content, and reads are limited to 30 a minute per person.

See [Admin](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/admin.md#logs) and [Connect an AI agent](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/connect-an-ai-agent.md).

## Upgrade

This version adds a database table for the log lines (migration `022_app_logs.sql`), applied when the app starts. Logs from before the upgrade aren't in the viewer. To give an existing Admin agent the `get_logs` tool, connect it again. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.0/guide/hosting.md) for upgrading in general.
