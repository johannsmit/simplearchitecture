# SimpleArchitecture 0.74.2

Each time someone reads the logs in Admin → Logs, the app's log records who read them.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Reading the logs is recorded** ([#89](https://github.com/johannsmit/simplearchitecture/issues/89)): the logs hold client addresses and user ids, so who looked at them should be traceable. A read in Admin → Logs was not recorded; a read by an AI agent through `get_logs` was. Every successful read, in Admin → Logs or by an agent, now writes a `logs-read` entry with the reader's user id, the range and the level asked for. The entry is itself shown in Admin → Logs. See [Security overview](https://github.com/johannsmit/simplearchitecture/blob/v0.74.2/guide/security-overview.md#logs-and-the-audit-trail).

## Upgrade

There are no database changes: start 0.74.2 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.2/guide/hosting.md) for upgrading in general.
