# SimpleArchitecture 0.73.0

AI agents can now add and change elements and relationships for Modellers, with the same checks as the app.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Write tools on the MCP endpoint** ([#11](https://github.com/johannsmit/simplearchitecture/issues/11)): `create_element`, `update_element`, `create_relationship` and `update_relationship`. They are there only for people with the Modeller role or higher. Viewers keep the read-only tools.
- **The same rules as the app.** Each change goes through the app's own validation and the metamodel's rules. An update sends the version the agent read, so it never overwrites a change made since.
- **Preview first.** Every write tool takes `dry_run`: the change is checked as a real save and the result is shown, but nothing is stored. Agents are told to preview and to save only after you confirm.
- **Marked in the audit trail.** A change an agent makes is recorded as yours, with a mark that it was made by an agent on your behalf.
- **Limits.** One element or relationship per call, and at most 60 write calls a minute per person, previews included.
- **`get_element` returns versions** for the element and its relationships, for the agent to send with an update.
- **The consent page and Connected apps say what the agent may do.** For a Modeller, it may add and change elements and relationships; no agent can delete anything.

See [Connect an AI agent](https://github.com/johannsmit/simplearchitecture/blob/v0.73.0/guide/connect-an-ai-agent.md).

## Upgrade

There are no database changes: start 0.73.0 in place of the older version. A connection keeps the roles it had when it was allowed: to give an existing agent the write tools, connect it again. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.73.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
