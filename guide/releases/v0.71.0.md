# SimpleArchitecture 0.71.0

Modelling saves your changes in the details panel as you go, without a Save button.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Auto-save in Modelling.** Changes to an element or relationship in the details panel save by themselves: text fields when you pause typing or leave the field, choices such as a type, a list, Direction, State or Reverse direction at once ([#20](https://github.com/johannsmit/simplearchitecture/issues/20)).
- **Save status in the panel head.** The head says **Saving…**, **Saved** or **Couldn't save** with the reason. A failed save keeps what you typed and offers **Try again**.
- **A field with an error isn't saved.** It keeps its message, and your other changes are still saved.
- **The Save bar and Discard changes are gone.** `Ctrl` + `Enter` (`⌘` + `Enter` on a Mac) now means **Save now**, and `Esc` no longer asks to discard. Leaving the form saves a waiting change first, and asks **Leave without saving?** only when the last change couldn't be saved.
- **Conflicts show as before:** when someone else changed the same element or relationship, nothing more is saved until you choose **Reload**.
- **New element** and **Add relationship** still create only on **Create** or **Add**.

See [Modelling](https://github.com/johannsmit/simplearchitecture/blob/v0.71.0/guide/modelling.md#saving) and [Keyboard shortcuts](https://github.com/johannsmit/simplearchitecture/blob/v0.71.0/guide/keyboard-shortcuts.md#forms-modelling).

## Upgrade

There are no database changes: start 0.71.0 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.71.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
