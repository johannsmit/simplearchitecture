# SimpleArchitecture 0.65.0

AI agents can now list a model's views and read what each one holds.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Agents read views.** A connected AI agent gets two more read-only tools. **List views** gives a model's views by name, with their folder and how many elements and relationships each holds. **Get view** gives one view's name, folder and Group by, with its elements and its relationships, read against the model as it is now: anything deleted from the model since is left out. The agent reads the views you can open in Viewing, with the same access (Viewer and higher). See [Connect an AI agent](https://github.com/johannsmit/simplearchitecture/blob/v0.65.0/guide/connect-an-ai-agent.md#what-the-agent-can-ask).

## Upgrade

There are no database changes: start 0.65.0 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.65.0/guide/hosting.md) for upgrading in general.

## Known issues

- The corners outside a Stakeholder's circle can still be clicked as part of the circle ([#63](https://github.com/johannsmit/simplearchitecture/issues/63)).
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
- A line between a Stakeholder circle and a card can have a small step where a straight line would fit ([#51](https://github.com/johannsmit/simplearchitecture/issues/51)).
