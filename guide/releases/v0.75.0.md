# SimpleArchitecture 0.75.0

Logs that are easier to read, and less personal data for AI agents.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Logs as text**: Admin → Logs now shows the entries as one read-only text panel, one line per entry, newest first: time, level, the whole message and the entry's other fields. The table and its Details buttons are gone, so nothing needs opening to read an entry. See [Admin](https://github.com/johannsmit/simplearchitecture/blob/v0.75.0/guide/admin.md#logs).
- **Masked ids and addresses for AI agents**: an Admin's AI agent reading the logs with `get_logs` now sees user ids and client addresses masked to their last 4 characters (`203.0.113.45` becomes `*****3.45`), because the entries can reach the agent's model provider. Admin → Logs still shows them in full. See the [Security overview](https://github.com/johannsmit/simplearchitecture/blob/v0.75.0/guide/security-overview.md#logs-and-the-audit-trail).

## Upgrade

There are no database changes: start 0.75.0 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.75.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
