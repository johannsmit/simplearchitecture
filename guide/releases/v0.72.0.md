# SimpleArchitecture 0.72.0

Help is now in the app: one page per space saying what you can do, with the mouse and with the keyboard.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Help in the account menu.** Choose your name at the top right, then **Help** ([#21](https://github.com/johannsmit/simplearchitecture/issues/21)). It opens an overview of the three spaces and your access to each, with a page each for Viewing, Modelling and Admin.
- **Each page says what you can do and how:** the tasks of that space, the pointer actions, and the keyboard shortcuts, with every key from [Keyboard shortcuts](https://github.com/johannsmit/simplearchitecture/blob/v0.72.0/guide/keyboard-shortcuts.md) on the page where it applies.
- **Every signed-in person can read every help page.** A page for a space you can't use says which role it needs; a page for a space you can use ends with a link to open it.
- **The README is shorter.** For using the app, it now points to Help and to [the guide](https://github.com/johannsmit/simplearchitecture/blob/v0.72.0/guide/README.md).

## Upgrade

There are no database changes: start 0.72.0 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.72.0/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
