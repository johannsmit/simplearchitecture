# SimpleArchitecture 0.74.4

A fix for screen-reader users in the details panel.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **A failed save is announced once**: when a change to an element or a relationship isn't saved and the form shows a message about it, screen readers now hear that message only. Before, the save status in the panel head announced the same failure a second time. A failure the form shows no message for, such as a field to fix, is still announced by the save status. See [Modelling](https://github.com/johannsmit/simplearchitecture/blob/v0.74.4/guide/modelling.md).

## Upgrade

There are no database changes: start 0.74.4 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.4/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
