# SimpleArchitecture 0.10.0

**Back up your database before you start this version.** It runs a migration that can't be undone, see below.

## What changed

- **No licence file any more.** The app runs fully for everyone from the first start. Admin → Licence, the licence banner, the "no valid licence" page and the "Licensed to" line in the user menu are gone, and so are the `/api/licence` routes. There is nothing to upload and nothing to renew.
- **Access is unchanged.** Each role has what it had with a valid licence. A person with no role still gets no access, and a visitor who isn't signed in still gets nothing but the sign-in page. Sign-in through your own OpenID Connect provider is part of the app and stays that way.
- **The documents moved.** The security overview is now `guide/security-overview.md`, release notes are in `guide/releases/`, and the default metamodel is in `metamodel/`, with its content unchanged.

The settings are the same ten as before: nothing to change on your host.

## Also new

- **Import a JGF file on Admin → Models.** A file saved by Export can be imported from the screen, as a new model with the same elements and relationships. The server validates it as it does any import.
- **The image is public,** at `ghcr.io/johannsmit/simplearchitecture`, and can be pulled and verified with no sign-in. See "Verify a release" in the README. Each release is pushed by digest and tagged only after it has passed its checks, its SBOM lists the web app's packages too, and the latest release is scanned every week.

## Upgrading

1. **Back up the database.**
2. Change the image tag to `0.10.0` and start it.

Migration 007 runs at startup, in one transaction, and drops the `licence` table, including any licence you uploaded. Everything else stays: models, sessions, branding and the audit trail, with its earlier rows about licence uploads.

**There is no way back without the backup.** An older image refuses a database that this version has migrated. To go back, restore the backup and start the older image. A licence file you were given is no longer needed.
