# SimpleArchitecture 0.63.0

Element properties are now defined by an Admin, as relation properties already are, so every element uses the same names in the same way.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **Element properties on Admin → Properties.** The page now has two lists, Element properties and Relation properties. An element property is **Text**, a **Choice** from a list, or a **Reference** to other elements of the same model. See [Properties](https://github.com/johannsmit/simplearchitecture/blob/v0.63.0/guide/properties.md).
- **On every element.** Every element of every type shows every element property, after its type's standard properties and before Functions, on the form and in the details panel. The catalog and its CSV get a column for each, and Text and Choice properties can be used in the filters and Group by.
- **No more Add field.** Modellers no longer add fields of their own to elements: new properties are added by an Admin. The app refuses a new key on an element from anyone.
- **Reference fields become Reference properties**, picked with `@` as before.
- **Values are kept as they are.** A value that doesn't fit its property, such as references under a Text property, is kept and shown as **Not text**, **Not a choice** or **Not a reference**, with a button to remove it.
- **Changing an element's type** keeps a standard property the new type doesn't have, marked **Was a property**, until you remove it.
- **Deleting an element property** deletes its values from every element in every model, once the Admin has typed its name. Deleting a Reference property also removes its references, so **Referenced by** changes.
- **Import** adds new keys on elements as element properties, marked From models, and the import result lists them.
- **AI agents** get an element's defined properties by name, under `definedProperties`, with a Reference as each element's id and name.

## Upgrade

1. **Back up the database.** There is no downgrade: an older version refuses the upgraded database, so to go back, restore the backup and start the older version.
2. **Start 0.63.0.** The database changes run automatically when the app starts, with nothing to do by hand.
3. **On that first start, the app turns every field added on elements into an element property**, in every model, marked **From models**, with its values kept. A field whose every value is a Reference becomes a Reference property; any other becomes Text.
4. **As an Admin, check Admin → Properties.** Rename the From models properties, make one a Choice, or delete one with its values. A field that held text on some elements and references on others became Text, and its references show as Not text: make it a Reference to flag the text values instead.
5. **Tell your Modellers** that Add field is gone, and that new element properties come from an Admin.

Coming from 0.60.0, this version also brings **Group by** on the canvas, saved with a view, and references from an element to other elements. Their database changes run in the same upgrade. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.63.0/guide/hosting.md) for upgrading in general.
