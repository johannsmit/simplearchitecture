# SimpleArchitecture 0.74.3

Small fixes to the guide, the in-app help and the security policy.

**Still a beta.** Back up your database before you upgrade, and please [report what you find](https://github.com/johannsmit/simplearchitecture/issues).

## What changes

- **The guide index lists the logs**: the index of the guide now names the logs among the pages of the Admin space, as [Admin](https://github.com/johannsmit/simplearchitecture/blob/v0.74.3/guide/admin.md) does.
- **Viewing help gives the `Esc` key in a relationship's details**: the Viewing help page now says that `Esc` in a relationship's details goes back to its element, as the [keyboard shortcuts](https://github.com/johannsmit/simplearchitecture/blob/v0.74.3/guide/keyboard-shortcuts.md#forms-modelling) already did.
- **The security policy is written as the product**: [SECURITY.md](https://github.com/johannsmit/simplearchitecture/blob/v0.74.3/SECURITY.md) no longer speaks in the first person. What it promises is unchanged.

## Upgrade

There are no database changes: start 0.74.3 in place of the older version. See [Hosting the image](https://github.com/johannsmit/simplearchitecture/blob/v0.74.3/guide/hosting.md) for upgrading in general.

## Known issues

- Without Discard, an accidental edit is saved. An "undo the last change" is planned.
- Widening a card can leave other lines running over it ([#47](https://github.com/johannsmit/simplearchitecture/issues/47)).
